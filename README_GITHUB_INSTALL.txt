GENESIS TO THE STARS — THE FIRST DAWN
Playable evolution and civilization prototype, Version 1

WHAT YOU GET
- index.html — browser game; plays on Windows and Android/iOS browser.
- manifest.webmanifest — installable app metadata.
- sw.js — caches the game for offline use after installation.
- icons/icon-192.png and icons/icon-512.png — launcher icons.

HOW TO PUT IT ON GITHUB PAGES
1. Unzip the downloaded archive.
2. Open your game's GitHub repository, the one with Pages enabled.
3. Upload index.html, manifest.webmanifest, sw.js, and the entire icons folder to
   the same GitHub Pages publishing directory. Don't upload the ZIP itself.
4. Publish normally. Open your live https://USERNAME.github.io/REPOSITORY/ URL.
5. On Android in Chrome, press the visible INSTALL ON PHONE button on the title
   screen. If Chrome doesn't display an installation prompt, open the Chrome
   three-dot menu and select Install app or Add to Home screen.
6. On iPhone in Safari, press Share, then Add to Home Screen.
7. The installed version runs without the browser address bar and caches the
   game for offline use after the first successful online load.

IMPORTANT
- index.html by itself still plays in a browser, but won't install as a
  fully cached PWA without the other files in this ZIP.
- Save slots use this device's browser storage; browser/private data clearing
  can erase them. Menu -> Export world file creates a portable backup JSON.
  Menu -> Import world file can restore that save.
- This is a self-contained chapter. It includes ecosystem survival, evolution,
  emerging culture and the first observatory, NOT a playable galaxy/space stage.
- Existing Everything Game and Ashen Vale projects are separate.
